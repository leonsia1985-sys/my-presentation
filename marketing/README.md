# 마케팅 원론 핵심 정리

코틀러 『마케팅 원리』 체계를 기준으로 1~12장의 핵심 개념과 예상 문제를 36장의 슬라이드로 정리한 학습용 발표 자료입니다.

## 보기

GitHub Pages로 배포되어 있으며, 브라우저에서 바로 열 수 있습니다. 로컬에서는 `index.html`을 열면 됩니다.

| 키 | 동작 |
| --- | --- |
| `→` / `Space` / 클릭 | 다음 (정답 공개 포함) |
| `←` | 이전 |
| `N` | 발표자 노트 보기 |
| `F` | 전체 화면 |
| `Home` / `End` | 처음 / 끝 |

특정 슬라이드로 바로 가려면 주소 끝에 `#slide-7`처럼 번호를 붙이세요. 브라우저 인쇄(PDF 저장) 시 한 장에 한 슬라이드씩 출력됩니다.

## 구성

- `index.html` — 슬라이드 36장과 뷰어
- `deck.css` — 공통 스타일
